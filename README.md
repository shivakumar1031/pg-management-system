# PG Management System

A Spring Boot REST API for managing PG accommodations, rooms, beds, tenants, stays, and payments.

## Features

- PG management
- Room management
- Bed management
- Tenant management
- Stay management
- Payment management
- RESTful CRUD APIs
- Entity relationships using JPA/Hibernate
- Input validation
- MySQL database integration
- API testing using Postman

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- REST APIs
- MySQL
- Maven
- Postman

## Project Structure

Controller → Service → Repository → Database

## How to Run

1. Clone the repository.
2. Configure MySQL in `application.properties`.
3. Create the required database.
4. Run the application using IntelliJ IDEA or Maven.
5. Test the APIs using Postman.
